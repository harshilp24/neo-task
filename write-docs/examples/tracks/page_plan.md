# Tracks: page plan

The plan the skill produced for Tracks, and where each page lives.

## User goals

| Goal | Role | Changes | How often | Page |
|---|---|---|---|---|
| Turn Tracks on for a project | member | the project | once | Tutorial |
| Add a track for each workstream | member | tracks | once | Tutorial |
| Start a task on its tracks | member | a task's status | daily | Reference (open gap: no steps yet) |
| Mark a track Done | member | a task's status | daily | Reference (open gap: no steps yet) |
| See where a task stands | member | nothing | daily | Reference, explanation |
| Add a track between two others | member | tracks | rarely | FAQ |
| Rename or reorder a track | member | tracks | rarely | FAQ |
| Delete a track | member | tracks | rarely | FAQ |
| Turn Tracks off | admin | the project | rarely | FAQ |
| Start several tasks at once | member | task statuses | sometimes | Manage tasks on tracks |
| Send a task back for more work | member | a task's status | sometimes | Manage tasks on tracks |
| Stop a task on a track | member | a task's status | sometimes | Manage tasks on tracks |
| Close or reopen a task with tracks | member | the task | sometimes | Reference, troubleshooting |
| Work offline | member | task statuses | sometimes | Manage tasks on tracks |

## Pages

| Type | Title | File | Reader | Covers |
|---|---|---|---|---|
| Overview | Tasket | `docs/tasket/index.mdx` | Anyone arriving | Three layers, a Tracks board preview, a card per page |
| Tutorial | Get started with Tracks | `docs/tasket/tracks/get-started.mdx` | First-time user | Turn on Tracks and add tracks, with the sign-in redesign as the example |
| How-to | Manage tasks on tracks | `docs/tasket/tracks/manage-tasks-on-tracks.mdx` | Someone moving work | Bulk start, send back, stop, offline |
| Explanation | What are Tracks? | `docs/tasket/tracks/what-are-tracks.mdx` | Anyone wanting the why | Problem, model, status-board comparison, when to use |
| Reference | Tracks reference | `docs/tasket/tracks/reference.mdx` | Someone looking up a fact | Statuses, actions, permissions, views, offline, effects, rules |
| FAQ | Tracks FAQ | `docs/tasket/tracks/faq.mdx` | Someone with a quick question | How do I add, rename, reorder, delete a track, turn Tracks off |
| Troubleshooting | Troubleshoot Tracks | `docs/tasket/tracks/troubleshooting.mdx` | Someone stuck | Ten issues (error, symptom, offline, permission, data loss), each with cause and solution |
| Release note | Tracks | `blog/2026-10-02-tracks.mdx` | Existing user | What's new, in 76 words |
