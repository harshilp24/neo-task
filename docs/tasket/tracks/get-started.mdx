[Tracks](./what-are-tracks.mdx) is a Tasket feature that lets one task sit on several workstreams at the same time, such as Spec and Design. Each track is a column on the project's **Tracks** board, and the task has its own status on each one: *Not started*, *Pending* or *Done*.

In this tutorial, you turn on Tracks for a project and add a track for each workstream.

## Before you begin

Make sure you have:

- **Access to the project.** Any team member can turn on Tracks and add tracks. Guests from other organisations can do the same on projects they can access.
- **A connection.** Turning on Tracks and adding tracks don't work offline.
- **A list of your workstreams.** Write down the teams or steps your tasks pass through. Each one becomes a track. Track names must be different from each other within the project.

## Add your tracks

1. In Tasket, open your project and click the **Settings** tab.

2. Turn on **Tracks**. A **Tracks** tab appears next to the project's **Open** tab.

   Anyone in the team can turn Tracks on. Only an admin can turn it off.

3. Open the **Tracks** tab, click **+ Add Track** and name the track.

   For example, name it `Spec` for the team that writes the spec.

4. Add more tracks the same way, one for each workstream your tasks pass through.

   For example, if you're redesigning the sign-in page, the work needs a spec, then design, then engineering, then QA. So add `Design`, `Engineering` and `QA`.

5. On the **Tracks** tab, you see a column for each track. Each column has:

   - ***Pending*:** tasks started on this track and still in progress.
   - ***Done*:** tasks marked Done on this track. Marking a task Done here doesn't change its status on any other track.
   - **Start:** a button in the column header that starts the tasks you've ticked in the task list on this track.

You've turned on Tracks for your project and added a track for each workstream.
