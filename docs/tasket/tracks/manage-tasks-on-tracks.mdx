Once a project has [tracks](./what-are-tracks.mdx), each task has its own status on every track: *Not started*, *Pending* or *Done*.

In this guide, you start a task on a track, mark it Done, start several tasks at once, send a task back, stop a task on a track, and work offline.

## Before you begin

Make sure you have:

- **Tracks turned on.** The project shows a **Tracks** tab. If it doesn't, follow [Get started with Tracks](./get-started.mdx).
- **Access to the task.** Anyone who can open a task can change its tracks, including guests.

## Start a task on a track

1. Open the task and click its **Tracks** pill.

   The pill lists every track in the project, with the task's status on each.

2. Click **Start** next to the track.

   The task appears in the track's *Pending* section. To start it on more tracks, click **Start** next to each one.

## Mark a track Done

When a track's work on the task is finished:

1. In the track's column, find the task in the *Pending* section.
2. Click **Mark Done**.

   The task moves to the *Done* section, and the column's counter updates. Its status on other tracks doesn't change, and the task stays open.

You can also click **Mark Done** next to the track in the task's Tracks pill.

## Start several tasks at once

This needs a connection.

1. On the **Tracks** board, tick each task in the task list.
2. In the header of the track you want them on, click **Start**.

   The tasks appear in the track's *Pending* section. Tasks already on the track stay where they are.

3. To start the same tasks on another track, click **Start** in that track's header.

## Send a task back for more work

1. In the track's column, find the task in the *Done* section.
2. Click **Mark Pending**.

   The task moves back to the *Pending* section. Its status on other tracks doesn't change.

## Stop a task on a track

This needs a connection.

1. In the track's column, find the task.
2. If the task is in the *Done* section, click **Mark Pending**.
3. Click **Stop**.

   The task leaves the column. Its Tracks pill shows *Not started* for that track.

You can also use **Mark Pending** and **Stop** from the task's Tracks pill.

## Work offline

**Start**, **Mark Done** and **Mark Pending** work offline. Tasket saves the change on your device and syncs it when you reconnect.

If someone deletes a track while you're offline, your changes to that track are discarded when you sync.
