Once a project has [tracks](./what-are-tracks.mdx), each task has its own status on every track: *Not started*, *Pending* or *Done*. This guide covers the changes that come up as tasks move through them.

In this guide, you start several tasks at once, send a task back, take a task off a track, and work offline.

## Before you begin

Make sure you have:

- **Tracks is on, and the project has tracks.** If not, follow [Get started with Tracks](./get-started.mdx).
- **Access to the task.** Anyone who can open a task can change its tracks, guests included.

## Start several tasks at once

You need a connection to do this.

1. On the **Tracks** board, tick each task in the task list beside the columns.

2. Click **Start** in the header of the track you want them on.

   The tasks appear in that track's *Pending* section. A task that was already on the track stays where it was.

3. To start the same tasks on another track, click **Start** in that track's header too.

## Send a task back for more work

If a track marked a task Done too early:

1. In the track's column, find the task in the *Done* section.
2. Click **Mark Pending**.

   The task moves back to the *Pending* section. Its status on other tracks doesn't change.

## Take a task off a track

If a task no longer needs a workstream:

1. In the track's column, find the task in the *Pending* section.

   If the task is *Done* on that track, click **Mark Pending** first. A Done task can't be stopped.

2. Click **Stop**.

   The task leaves the column, and its Tracks pill shows *Not started* for that track.

You can also send a task back or stop it from the task's Tracks pill.

## Work offline

Starting a task on a track, **Mark Done** and **Mark Pending** work without a connection. Tasket saves them on your device and syncs them when you reconnect.

**Stop** and starting several tasks at once need a connection.

If someone deletes a track while you're offline, any changes you made on that track are discarded when you sync.
