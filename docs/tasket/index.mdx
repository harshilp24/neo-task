## What you can do in Tasket

| Area | Features |
|---|---|
| **Teams** | Create teams · Invite guests |
| **Projects** | Create projects · Configurable projects · Plan sprints · Accept intakes · Configure custom fields |
| **Tasks** | Organise tasks · Add comments · Add documents · Add AI chats |
| **Workflows** | [Tracks](/docs/tasket/tracks): define workflows made of several steps |
| **Your work** | Work tab · Updates tab · Silence Score |

Tracks is documented here. Docs for the other features are on the way.
